# 【大促目标测算】历史操作版本记录留存

## 需求概述

在「大促-目标测算」模块中新增版本控制功能，实现全链路操作留痕、历史版本追溯与回退能力，确保目标测算过程可审计、可回溯。

---

## 一、新增版本留痕入口与表格展示

### 1.1 功能位置
在「预算测算&调配 / 目标测算 / 促中监控」导航栏正下方，新增横向版本控制条。

### 1.2 界面布局

```
┌─────────────────────────────────────────────────────────────────────────┐
│  预算测算&调配   |  目标测算   |  促中监控                               │
├─────────────────────────────────────────────────────────────────────────┤
│  [V2.1]          [版本历史]  [导出当前版本]                              │
└─────────────────────────────────────────────────────────────────────────┘
```

### 1.3 版本控制条说明

| 元素 | 说明 |
|------|------|
| 版本号标签 | 橙色背景圆角标签，显示当前版本号（如 V2.1、V2.2） |
| 版本历史按钮 | 文字按钮，点击弹出下拉列表 |
| 导出当前版本按钮 | 文字按钮，点击生成飞书文档 |

### 1.4 版本历史下拉列表

**列表规格：**
- 宽度：420px
- 每条记录高度：48px
- 排序：按版本号倒序（最新版本在最上方）

**每条记录展示字段：**
| 字段 | 位置 | 样式 |
|------|------|------|
| 版本标识（✅/📝） | 左侧 | ✅ = 已生效（绿色背景行）<br>📝 = 历史版本 |
| 版本号 | 左侧 | 加粗文本 |
| 操作人 | 左侧 | 灰色小字 |
| 操作说明 | 左侧 | 灰色小字，1行截断 |
| 操作类型标签 | 右侧 | 圆角标签，带颜色 |
| 操作时间 | 右侧 | 灰色小字 |

### 1.5 操作类型枚举（共11类）

| 操作类型 | 标签颜色（背景/文字） | 适用场景 |

| 阶段目标调整 | 橙色 #FFF3E0 / #EF6C00 | 新增/修改大促分阶段目标 |
| 调整申请通过 | 绿色 #E8F5E9 / #2E7D32 | 业务方发起的目标调整申请审批通过 |
| 调整申请驳回 | 红色 #FFEBEE / #C62828 | 目标调整申请被驳回 |
| 目标下发 | 紫色 #EDE7F6 / #7B1FA2 | 资管将最终目标下发给中台/大促组 |
| 上传CRM | 绿色 #E8F5E9 / #2E7D32 | 目标自动同步上传至CRM系统 |
| 版本回退 | 灰色 #F5F5F5 / #424242 | 切换回历史版本生效 |

## 二、导出当前版本

### 2.1 功能入口
点击版本控制条右侧「导出当前版本」按钮。

### 2.2 交互流程

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  点击按钮     │ ──▶ │  Loading状态  │ ──▶ │  成功提示框   │
└──────────────┘     └──────────────┘     └──────────────┘
                          「正在生成...」      飞书文档已生成
```

### 2.3 按钮状态

**默认状态：**
```
[导出当前版本]
```

**Loading状态：**
```
[↻ 正在生成...]  （禁用点击）
```

### 2.4 飞书文档生成规则

**文档标题格式：**
```
【{大促活动名称}】目标测算报告（V{版本号}）（此版本最后更新时间）
```

**示例：**
```
【双11 预售期】目标测算报告（V2.2）（2026-10-15 17:05）
```

**文档内容包含：**
- 基础配置信息
- 目标配置数据
- 分行业GMV预测
- 分日预测图表数据
- 敏感性分析
- 当前版本信息

### 2.5 成功提示框

**位置：** 页面右上角（top: 80px, right: 24px）

**样式：**
```
┌─────────────────────────────────────┐
│  ✅  飞书文档已生成                  │
│      【双11 预售期】目标测算报告（V2.2）│
│                                     │
│      [🔗 打开飞书文档]    [×]       │
└─────────────────────────────────────┘
```

**交互：**
- 点击「打开飞书文档」跳转新标签页
- 点击 × 关闭提示框
- 5秒后自动关闭
- 点击外部区域关闭

### 2.6 权限配置

| 配置项 | 说明 |
|------|------|
| 可见范围 | 同组织可见 |
| 创建者 | 对话发起人（对应资管角色） |
| 权限继承 | 统一此对话权限 |

## 三、版本回退

### 3.1 权限控制

| 角色 | 可见性 |
|------|-------|
| 资管 | ✅ 可查看历史版本 + 显示「恢复此版本」按钮 |
| 中台/大促组 | ❌ 隐藏「恢复此版本」按钮 |

### 3.2 历史版本视图

当用户切换到历史版本时，页面顶部显示黄色提示条：

```
┌─────────────────────────────────────────────────────────────────────────┐
│  ⚠️ 已切换至历史版本，仅支持查看不可编辑   [返回最新]  [恢复此版本]        │
└─────────────────────────────────────────────────────────────────────────┘
```

**交互说明：**
- 「返回最新」：返回当前生效版本视图
- 「恢复此版本」：点击弹出确认弹窗

### 3.3 回退确认弹窗

```
┌───────────────────────────────────────────────────────┐
│                                                       │
│   →  确认版本回退                                     │
│       目标版本：V1.2                                   │
│                                                       │
│   确认要回退到该历史版本吗？                           │
│   回退后将生成新的版本记录，                           │
│   当前最新版本会自动存档。                             │
│                                                       │
│   [取消]              [确认回退]                       │
│                                                       │
└───────────────────────────────────────────────────────┘
```

**按钮说明：**
- 「取消」：灰色按钮，关闭弹窗
- 「确认回退」：橙色主按钮，执行回退操作

### 3.4 回退成功提示

**位置：** 页面顶部居中

```
┌─────────────────────────────────────────────────────────────────────────┐
│     ✅ 已成功回退至V1.2版本，新版本号为V2.3                              │
└─────────────────────────────────────────────────────────────────────────┘
```

**提示特点：**
- 绿色背景
- 3秒后自动关闭
- 显示原版本号和新版本号

### 3.5 版本记录自动生成

回退成功后，系统自动新增一条版本记录：

| 字段 | 值 |
|------|-----|
| 版本号 | 新版本号（如 V2.3） |
| 操作人 | 当前登录用户（资管角色） |
| 操作时间 | 回退操作时间 |
| 操作类型 | 版本回退（灰色标签） |
| 操作说明 | 回退至历史版本V{原版本号} |
| 状态 | ✅ 已生效 |

### 4.2 版本记录数据结构

```typescript
interface VersionRecord {
  version: string;           // 版本号，如 "V2.2"
  operator: string;          // 操作人，如 "秦娇芸（资管）"
  time: string;             // 操作时间，如 "2026-10-15 17:05"
  type: OperationType;      // 操作类型
  description: string;      // 操作说明
  status: 'active' | 'history';  // 状态
}

type OperationType = 
  | '信息导入'
  | '配置更新'
  | 'AI测算生成'
  | 'AI重新校准'
  | '人工修改数值'
  | '阶段目标调整'
  | '调整申请通过'
  | '调整申请驳回'
  | '目标下发'
  | '上传CRM'
  | '版本回退';
```
