# 预算分配优化模块 - 研发需求文档

## 1. 功能概述

预算分配优化模块是AI预算助手的核心功能，为业务预算管理者提供智能预算分配方案。模块通过三栏式布局展示：左侧配置项区域、中间预算分配工作台、右侧实时效果预测。

### 1.1 核心目标
- 展示AI算法推荐的预算分配方案
- 支持用户手动调整预算分配
- 实时预览调整后的效果预测
- 提供方案应用、导出、审批等功能

#### 2.2.3 一级分配方向调整功能

**功能描述：**
- 用户可以直接修改三个一级方向的总预算金额
- 修改后，该方向下的所有二级玩法按比例自动调整

**交互逻辑：**

1. **输入框设计：**
   - 显示货币符号 "¥"
   - 数字输入框
   - 单位 "w"
   - 有最小值和最大值限制
   - 焦点时显示边框高亮

2. **各方向的取值范围：**
   - GMV增长方向：min=1000, max=3500
   - DAU增长方向：min=800, max=3000
   - DAC优化方向：min=500, max=2000

3. **自动按比例调整逻辑：**
   ```typescript
   function updateCategoryTotal(category: 'gmv' | 'dau' | 'dac', newTotal: number) {
     const oldTotal = budgetData[category];
     const items = budgetData[`${category}Items`];
     
     // 计算比例
     const ratio = newTotal / oldTotal;
     
     // 按比例调整每个子项
     const updatedItems = items.map(item => ({
       ...item,
       value: Math.round(item.value * ratio)
     }));
     
     // 处理四舍五入误差，确保总和精确
     const currentSum = updatedItems.reduce((sum, item) => sum + item.value, 0);
     const diff = newTotal - currentSum;
     
     if (diff !== 0) {
       updatedItems[0] = {
         ...updatedItems[0],
         value: updatedItems[0].value + diff
       };
     }
     
     return updatedItems;
   }
   ```

4. **样式要求：**
   - GMV方向：绿色主题（text-green-800, border-green-200, focus:ring-green-500）
   - DAU方向：蓝色主题（text-blue-800, border-blue-200, focus:ring-blue-500）
   - DAC方向：橙色主题（text-orange-800, border-orange-200, focus:ring-orange-500）

2. **各玩法的取值范围：**
   - GMV玩法：min=100, max=1200
   - DAU玩法：min=100, max=1000
   - DAC玩法：min=100, max=600

3. **更新逻辑：**
   ```typescript
   function updateBudgetItem(category: 'gmv' | 'dau' | 'dac', index: number, newValue: number) {
     const items = [...budgetData[`${category}Items`]];
     const oldValue = items[index].value;
     const diff = newValue - oldValue;
     
     items[index] = { ...items[index], value: newValue };
     
     return {
       items,
       categoryTotal: budgetData[category] + diff
     };
   }
   ```

## 3. 交互逻辑总结

### 3.1 实时更新机制
- 用户调整一级或二级预算后，右侧预测数据**立即更新**
- 无需点击确认按钮
- 更新过程有平滑的视觉反馈

### 3.2 数据校验
- 一级方向输入框有最小值和最大值限制
- 超出范围时无法输入或自动截断
- 输入非数字时自动忽略

### 3.3 状态管理
- 使用React useState管理预算数据
- 数据变更时自动触发重新渲染
- 右侧预测数据基于当前预算数据计算

## 5. 技术实现要点

### 5.1 状态管理
```typescript
const [budgetData, setBudgetData] = useState<BudgetData>({...});
```

### 5.2 计算逻辑
- 一级方向调整：按比例缩放子项，处理四舍五入误差
- 二级玩法调整：累加差值到一级总预算
- 占比计算：`Math.round(value / total * 100)`

### 5.3 性能优化
- 使用React.memo避免不必要的重渲染
- 预测数据计算使用useMemo缓存
- 大列表使用虚拟滚动（如需要）

### 5.4 响应式设计
- 表格使用overflow-x-auto支持横向滚动
- 在小屏幕上调整布局（如需要）
