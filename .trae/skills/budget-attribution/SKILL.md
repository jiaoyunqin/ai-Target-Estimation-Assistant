# 预算指标（费率）归因分析 (Budget Attribution)

此 Skill 用于帮助用户系统性地分析和归因预算指标（特别是比率型指标，如费率、利润率、ROI等）的波动原因。

## 🎯 核心能力 (What it does)
- **差异拆解**：将整体预算指标（如整体营销费率）的实际与预算（或同期）差异，拆解到各个子维度（如渠道、产品线、地区）。
- **影响因子剥离**：使用连环替代法（Factor Substitution）或类似方法，将比率指标的变动剥离为“结构影响（Mix Effect）”和“效率影响（Rate/Efficiency Effect）”。
- **归因报告生成**：生成结构化的数据表格和业务洞察，直观展示哪些业务模块拉高或拉低了整体指标。

## 💡 使用场景 (When to use)
- 用户需要分析某个财务或业务指标为何偏离了预算（Budget vs Actual 分析）。
- 用户需要拆解费率（如退换货率、履约费率、ROI）的上升或下降是由哪些底层因素或子业务导致的。
- 用户提供了两期数据或预算/实际数据，要求找出核心变动原因。

## 📊 归因分析方法论 (Methodology)

当执行归因分析时，请严格遵循以下步骤：

1. **明确指标定义与维度**
   - 确认指标公式：如 `总体费率 = 总费用 / 总收入`。
   - 明确拆解维度：确认用户希望按照什么维度拆解（如按产品线）。如果用户未提供，主动询问。
   
2. **构建归因模型（以费率为例）**
   总体费率等于各子维度费率按其收入占比的加权平均：
   `总体费率 = Σ (子维度收入占比 × 子维度费率)`
   
   总差异 (Δ总体费率) = 实际总体费率 - 预算总体费率。
   总差异可以拆解为两部分：
   - **结构影响 (Mix Effect)**：由于业务结构变化（如高费率的业务占比提升）导致的总体费率变动。
     `结构影响 = Σ [(实际收入占比 - 预算收入占比) × 预算费率]`
   - **效率/费率影响 (Rate Effect)**：由于各个子业务自身费率变化导致的影响。
     `效率影响 = Σ [实际收入占比 × (实际费率 - 预算费率)]`
   *(注：也可使用两者的平均权重进行更平滑的拆分，视具体数据而定)*

3. **执行计算与验证**
   - 确保 `总差异 = Σ 结构影响 + Σ 效率影响`。
   - 对数据进行核对，避免计算错误。

4. **输出标准分析报告**
   分析报告必须包含以下结构：
   - **结论摘要 (Executive Summary)**：一句话概括核心结论（如：“整体费率上升0.5%，主要受A产品线费率恶化（效率影响）驱动，但部分被低费率的B产品线收入占比提升（结构影响）所抵消”）。
   - **归因数据表 (Attribution Table)**：以 Markdown 表格展示各维度的期初/预算值、期末/实际值、结构影响贡献、效率影响贡献及总贡献。
   - **业务洞察与建议 (Business Insights)**：基于数据结果，提出针对性的业务建议。

## 🗣️ 交互准则 (Interaction Guidelines)
1. **数据收集**：如果用户仅提出了分析需求但未给数据，先请用户提供具体的对比数据（如包含收入、费用的原始表格或 JSON）。
2. **主动计算**：如果用户已经提供了数据，直接应用上述方法论进行深度计算，无需反复询问。
3. **清晰展示**：尽量使用表格和加粗文本突出重点数据（如最大的正向/负向影响因子）。
